BSharp 語言簡介

BSharp (B#) 是一種簡潔、優雅且功能強大的腳本語言。它採用縮排式語法（Indentation-based），旨在提供極佳的可讀性與直觀的編程體驗。

核心特性

  • 縮排式區塊結構 (不使用 {})
  • 強大的比較運算子鏈結
  • 動態步長 For 迴圈
  • 自動變數作用域管理

資料類型

BSharp 支援以下基礎類型：

類型 範例 說明
Number 3.14, 42 雙精度浮點數
Boolean true, false 布林值
Null null 表示空值

運算子

算術運算

+  -  *  /  %  ^ (次方)  ! (階乘)

比較運算 (支援鏈結)

==  !=  >  <  >=  <=

支援 Python 風格鏈結：a < b < c

邏輯運算 (支援短路求值)

and  or  xor  not

註解

使用 # 進行單行註解。

# 這是一段註解
x = 10 # 也可以在代碼後方註解

運算優先級 (由高至低)

等級 運算子 說明
1 ( ) 括號
2 ! 階乘 (Postfix)
3 ^ 次方 (右結合)
4 -, not 負號、邏輯非 (Unary)
5 *, /, % 乘、除、取餘
6 +, - 加、減
7 ==, !=, >, <, >=, <= 比較運算
8 and, or, xor 邏輯運算
9 =, +=, -= ... 賦值運算 (最低)

變數與賦值

變數不需要宣告，直接賦值即可使用。

x = 10
y = x + 5
# 複合賦值
x += 1
y *= 2

支援的賦值運算子

= += -= *= /= %= ^=

控制流

使用 do 關鍵字引導區塊，並透過縮排定義層級。 

score = 85
if score >= 90 do
    result = "A"
else if score >= 80 do
    result = "B"
else
    result = "C"

迴圈

While 與 Until

i = 0
while i < 5 do
    i
    i += 1

until i == 10 do
    i += 1
    i

For 迴圈

語法：for var = start ~ end [: step] do

# 0 到 9，步長 2
for i = 0 ~ 10 : 2 do
    i

# 動態步長 (步長在每次迭代都會重新計算)
for i = 1 ~ 20 : i do
    i
動態步長: step 是一個表達式，它在每次迴圈迭代時都會重新求值。這允許步長根據變數的當前狀態動態變化。

當 for i = a ~ b do... 時，i 的範圍為 a ≤ i < b (左閉右開)。

迴圈控制

支援 break 與 continue：

  • break: 立即終止並跳出當前迴圈。
  • continue: 跳過本次迭代，進入下一次迴圈。

函式 (Functions)

BSharp 支援使用 fn 關鍵字定義函式。

表達式函式

對於簡單的運算，可以使用 = 直接定義返回值： 

fn add(a, b) = a + b
print(add(5, 3)) # 輸出 8

區塊函式

對於複雜的邏輯，使用 do 引導區塊，並使用 return 返回： 

fn factorial(n) do
    if n <= 1 do
        return 1
    return n * factorial(n - 1)

print(factorial(5)) # 輸出 120
遞迴支援: 函式可以呼叫自身，適合處理遞迴演算法。

內建函式

BSharp 提供了一些內建函式來協助開發：

函式 說明
print(args...) 將參數輸出至控制台。
input(prompt?) 從控制台讀取一行輸入。可選提供提示字串。
type(obj) 返回物件的類型名稱字串（如 "Number", "String"）。
assert(cond) 斷言條件為真，若為假則拋出錯誤。

作用域

BSharp 採用嵌套式作用域（Nested Lexical Scoping）：

  • 區域化: if, while, until, for 區塊內建立的新變數僅在該區塊內有效，結束後會自動刪除。
  • 向外查找: 內層作用域可以存取並更新外層作用域中已存在的變數。
  • For 迴圈變數: for i = 0 ~ 10 do 中的 i 被視為該迴圈的區域變數，不會影響外部的 i。 
x = 10
if true do
    x = 20 # 更新外層變數
    y = 5  # 建立區域變數
x # 結果為 20
y # 錯誤：變數 y 已被銷毀

REPL 與執行

執行檔案：

./BSharp.exe script.bs

進入 REPL：

./BSharp.exe
REPL 技巧:
  • 輸入空行可觸發執行。
  • REPL 會自動顯示最後一個表達式的計算結果，因此在測試時不一定需要使用 print。
  • 輸入 exit 可退出 REPL。
